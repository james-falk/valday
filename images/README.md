# Image Files Needed

Add the following images to this folder:

## Your Heads (Required)
- **head1.png** - Your cutout head (transparent background)
- **head2.png** - Her cutout head (transparent background)

## Pets (Required)
- **dog.png** - Your dog's photo (transparent background recommended)
- **cat1.png** - Cat #1 photo (transparent background recommended)
- **cat2.png** - Cat #2 photo (transparent background recommended)
- **cat3.png** - Cat #3 photo (transparent background recommended)

## Tips:
- Use [remove.bg](https://remove.bg) to remove backgrounds easily
- Recommended size: 300x300px or similar
- PNG format with transparent background works best
- Square crop works better for circular displays

The animations will still work without the images (fallback emojis will show), but it's much better with real photos!
